# Preserved original specifications and reports

These files are historical comparison material, not current specifications.

- `original-PRDs/`: byte-for-byte copies of all 32 original problem files and their README.
- `original-README.md`: the original repository landing page.
- `original-latex-reports/`: all 30 original TeX sources and PDFs, preserved before the 2026-09-17 replacement.
- `original-synthesis/`: the original synthesis Markdown, TeX and PDF, preserved at the source commit recorded below.

The original source commit and SHA-256 hashes remain unchanged in [source-manifest.json](../reviews/source-manifest.json). The validator resolves original report paths to their archive locations and checks those bytes. Historical draft DOCX/TXT files remain at their original paths.

Use the [current reports](../latex-reports/README.md) or [complete summaries](../COMPLETE-PROBLEM-SUMMARIES.md) for the reviewed formulations.
