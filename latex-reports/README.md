# Revised research reports

Updated 2026-09-17. These self-contained LaTeX/PDF reports follow the revised specifications, detailed critiques and shared evidence standard. Each includes a plain-language guide, scoped mathematical target, displayed formulation, deliverables, rejection controls and milestones. Canonical reports also reproduce their detailed critique; supplemental specifications already include it.

The reports replace unchecked historical derivations and code sketches with the reviewed research contracts. They do not claim that the proposed research has been carried out. [Original reports](../archive/original-latex-reports/) remain available for comparison.

## Reproducible generation

Run `python3 scripts/build_reports.py --pdf` from the repository root. Requirements: Python 3, Pandoc and XeLaTeX with its standard packages/fonts. Generated TeX files are standalone and can also be compiled with XeLaTeX directly. `--check` detects generated-text drift; `--only 21-` selects one PDF build; `--jobs 4` controls parallel compilation. Intermediate logs are kept in ignored `work/report-build/`.

Edit the canonical PRD/supplemental document, critique or shared `reviews/MATHEMATICAL-FORMULATIONS.md`, then regenerate. Do not edit generated TeX directly. PDF source links point to repository paths on GitHub; new links become live when this revision is published.
