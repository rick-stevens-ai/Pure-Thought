The links below identify coverage, not equivalence: a related PRD can address a different observable. In particular, an error-correcting code is not an anyon-condensation classification, an RNA mutation graph is not a channel-capacity theorem, and a topological band is not necessarily an optimized complete wave gap.

## Editorial implications

The synthesis correctly identifies the SCE functional, whereas PRD 18 changes it into an incorrect exact-exchange claim; the rewrite restores the former target. Several original synthesis topics disappear entirely from the PRD titles, while the PRDs add HOTIs, semimetals, reaction dynamics, path integrals, entanglement measures, and general quantum algorithms. None of those additions is treated as a substitute for the missing topic without a mapping.

The draft directory is retained as ideation history. Its overlapping domain brainstorms are not treated as an additional approved challenge catalog. This review inventories those sources and uses the numbered PRDs and numbered synthesis as the two explicit problem lists. It does not claim a sentence-by-sentence technical audit of all draft transcripts, their DOCX copies, or every equation and program in the long-form reports.
